# Rogue Assistant — v0.1.0-beta.2

Every element on screen can now be moved, and the poison list can open to any side of the button.

> ⚠️ **Beta:** everything is covered by automated tests, but **nothing has run in the game client yet**. Several spell and item ids are Classic Era ids that are not confirmed for Forever, so an icon may be missing or a poison may not be recognised on the first try. Please run `/ras debug probe` (and `/ras debug bags`, `/ras debug spells`, `/ras debug auras`) and include the output when you report a problem.

## ✨ What's new

- **Everything is movable.** `/ras unlock` now unlocks the tracker groups, the poison button, the weapon status lines and the alert banner. While unlocked, each one shows a highlighted background and its name; `/ras lock` fixes them again. Nothing moves in combat
- **Alert banner:** drag it where you want. While unlocked it stays on screen with a sample text and a labelled handle, and it hides again on lock unless a reminder is showing
- **Weapon status lines:** they are now a separate element, movable on their own. They sit under the poison button until you move them, and you can hide them in the options
- **Poison list direction:** choose whether the list opens up, down, left or right of the button. Changing it in combat is applied when combat ends
- **Options panel:** a button at the top to unlock and lock all elements (the same as `/ras unlock` and `/ras lock`), a *Reset all positions* button, the list direction selector and a switch for the weapon status lines
- English and Spanish texts for all of the above
