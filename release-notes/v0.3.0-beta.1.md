# Rogue Assistant — v0.3.0-beta.1

A minimap button, a cleaner bar, and a timer for both the poison and the stone on each weapon.

> ⚠️ **Beta:** covered by automated tests. The poison and weightstone timers were checked against real Forever data; the rest has not run in the game client yet. Please include the output of `/ras debug bags` and `/ras debug weapon` when you report a problem.

## ✨ What's new

- **Minimap button:** click it for a menu to unlock or lock the bar, reset its position or hide the button. Drag it around the minimap. `/ras minimap` shows it again
- **Poison and stone timers:** on Forever a weapon can carry a poison and a stone at once. Under each button you now see a small poison icon with the poison's time left and a small stone icon with the stone's (weightstones and oils too). The poison's charges are shown above the button
- **Weapon icon:** each button shows your weapon's icon, with no tooltip
- **Drag area:** while the bar is unlocked, a highlighted area covers the buttons so you can drag the bar; locked, only the buttons are shown
- **Debugging:** `/ras debug weapon` prints every value the game reports for your weapons and the lines of their tooltips
- English and Spanish texts

## 🐛 Fixes

- Applying an item from the list now works with the game's default *cast action keybinds on key down* setting
