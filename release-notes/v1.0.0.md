# Rogue Assistant — v1.0.0

The first stable release: poisons, stones and oils one click away, with a timer for each one on your weapons.

## ✨ What's new

- **Stone timer in seconds:** the stone's timer now counts down second by second (4:12, 4:11…) like the poison's, instead of jumping a whole minute at a time. Right after a reload the first minute can be off by a few seconds until the game updates the stone's time
- Stable release: no longer marked as beta on CurseForge
